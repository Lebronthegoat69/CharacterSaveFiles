 Character Save Files

 Project Description

This Java project demonstrates how to store video game character data using JSON and XML files. The program creates three game character objects, stores them in a list, writes their information to both file formats, and reads and displays the saved contents.

#Characters

The program creates the following characters:

- **Brutus** — Warrior, Level 5
- **Elara** — Mage, Level 7
- **Rowan** — Archer, Level 4

Each character includes a name, character class, level, health, attack power, and gold.

 Files

- `GameCharacter.java` — Defines the game character class, constructor, getter methods, and `toString()` method.
- `Main.java` — Creates the characters, writes the files, and reads and displays their contents.
- `characters.json` — Stores character data in JSON format.
- `characters.xml` — Stores character data in XML format.

 How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure a compatible Java Development Kit (JDK) is configured.
3. Open `Main.java`.
4. Run the `main()` method.
5. Check the console output to see the characters and the contents of both files.

The program uses Java file I/O and exception handling to create, write, and read the files.

 JSON and XML Comparison

JSON and XML both organize character information into structured data. JSON uses key-value pairs and is generally easier to read because it is more concise. XML uses opening and closing tags, which makes it more repetitive. Both formats can store the same character information and make it easier for programs to organize and process data than an unstructured block of text.
